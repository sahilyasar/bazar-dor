# বাজার দর / BazarDor

A simple Bangla website to check daily prices, compare markets, and track price changes for everyday products.

## Technologies Used

- Next.js and React
- JavaScript
- Tailwind CSS and DaisyUI
- Better Auth and MongoDB
- React Hot Toast

## Key Features

1. **Daily prices** — Browse product prices and see which prices have increased or decreased.
2. **Categories** — Filter products by category and sort by price.
3. **Market comparison** — View minimum, maximum, and average prices across markets.
4. **User accounts** — Sign up, sign in with email or Google, and update your profile name.
5. **Responsive design** — Mobile-friendly pages with a price ticker, loading skeletons, toast messages, and a custom 404 page.
